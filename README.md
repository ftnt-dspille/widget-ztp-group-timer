# ZTP Group Timer

Ticks up from the run group's earliest step start once it begins, and freezes at its total once every started step has stopped. Pick from a few visual themes (digital LCD, flip digits, minimal text, spinner ring, compact badge) in Edit Config.

A FortiSOAR widget (`ztpGroupTimer` 1.0.3). Package the folder that holds `info.json` as a `.tgz` and import it from the Widget Library.
